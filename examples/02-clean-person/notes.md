# 02｜CLEAN：人物

只清理原稿的说服腔、空泛赞语和听觉负担。年份、获奖次序、合作关系、发现归属、接任职位和「第一位」的范围均保留。末段不把坚持写成成功的充分条件。

| 原句 | 改句 | 理由 |
| --- | --- | --- |
| 「一段改写人类科学史的传奇」 | 「居里夫人两次获得诺贝尔奖。」 | 从可核的事实开口，去掉无信息的评价。 |
| 「她在 1903 年获得博士学位，同一年与皮埃尔分享诺贝尔物理学奖。」 | 「1903 年，她获得博士学位。同一年，她与皮埃尔分享诺贝尔物理学奖。」 | 降低听觉负担，保留时间和合作归属。 |
| 「她参与发现了钋和镭，后来又因相关研究获得 1911 年诺贝尔化学奖。」 | 「她还参与发现了钋和镭。到 1911 年，她又因相关研究获得诺贝尔化学奖。」 | 保留原稿的发现归属与「相关研究」的范围。 |
| 「只要坚持，就一定能创造奇迹。」 | 「但这不等于一个保证：只要坚持，就一定能得到同样结果。」 | 保留「坚持」这个原稿态度，同时把未经证实的普遍承诺降级。 |

**保留了什么：** 1891 年求学、1903 年博士与物理学奖、1906 年皮埃尔去世、1911 年化学奖、贝克勒尔的发现、与皮埃尔合作、钋和镭、第一位女性获奖者及接任教授职位的范围。

**事实待核：** 无。时间与奖项依据[诺贝尔奖官网人物传记](https://www.nobelprize.org/prizes/chemistry/1911/marie-curie/biographical/)和[1903 年事实页](https://www.nobelprize.org/prizes/physics/1903/marie-curie/facts/)；本文为原创表述。
