# 选题：冰水杯外面的水珠从哪里来？

面向刚开始接触科学解释的普通观众。主问题是：杯子没有漏水，外壁为什么会湿？从一只装冰水的透明杯出发，沿着「擦干外壁 → 等一会儿 → 重新出现水珠」讲清空气中的水蒸气遇冷凝结。不要把杯中水说成穿过杯壁，也不要声称所有天气下都会出现同样多的水珠。

事实依据：[NASA 关于冷杯外壁水珠的教学材料](https://assets.science.nasa.gov/content/dam/science/cds/eclips/assets/documents/nasa-spotlite-interactive-lesson-composition-of-earths-atmosphere-student.pdf)；[NASA 对凝结的解释](https://science.nasa.gov/kids/earth/how-do-clouds-form/)。
