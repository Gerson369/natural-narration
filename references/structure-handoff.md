# CLEAN 停止条件与交回编剧（v0.9.0）

语言清洗解决不了结构。发现下面任一情况，**停止换词**，写问题报告，交回叙事编剧：

- 主问题在某几段断线：段落没有回答上一个疑问，也没有引出下一个。
- 段落按资料顺序并列，没有形成解释链。
- 规则介绍独立成教程，没有放进演示过程。
- 场景只有环境描述，不帮助理解任务、限制、选择或后果。
- 结尾只重复开头，没有理解变化。

## 问题报告格式（附在正文后，一处一行）

```
结构需重组：
- 第 N 段：[问题]，原因：[具体说明]。建议交回编剧处理：[当前疑问 / 交付答案 / 新增理解 / 下一问 中缺哪一项]
```

## 不做

- 不反复运行 CLEAN 掩盖结构问题。
- 不在 CLEAN 里增删观点、调整段落顺序。
- 用户明确要求本 Skill 重写时，才按首稿蓝图、只用原稿事实重写。
