# Practical Value Router｜实用价值路由（v0.3.0 新增）

这项能力**不全局启用**。强行给所有题材加行动清单，会造出另一种模板。

## 启用范围

启用（必须给出可执行内容）：

- 方法论、工作方式
- 商业、创作者经营、一人公司
- 个人成长、习惯、学习方法
- 工具与流程教学
- 慢创业类内容

不启用（保持解释属性）：

- 硬核科普、宇宙、物理、生物
- 历史人物、人物故事
- 纪录片式叙述
- 新闻背景解释
- 纯定义、纯清单、纯操作步骤（这类只走清晰度检查）

判断方式：观众听完之后，**是否本来就期待自己做点什么**。是 → 启用；不是 → 不启用。

## 启用后的四项要求

1. **一个具体动作**：可以今天或本周做，能判断做完没做完。
2. **一个使用场景**：在什么场合、面对谁、什么时候用。
3. **一个限制条件**：什么情况下无效或不适用。
4. **一个常见失败点**：多数人会在哪一步做错。

四项里缺两项以上 → 内容停留在「觉悟层」，回到事实层补。

## 伪实用清单

下面这些不算行动建议：

提升自己、保持长期主义、建立系统、找到热爱、持续积累、提高认知、多读书、坚持下去、深耕、努力就好。

判定三问：

1. 具体先做什么？
2. 什么时候做？
3. 怎么判断做完了？

三问答不上 → 改写或删掉，不要留一个听起来正确的空句。

## 对照

**差**

> 想做好内容，关键是持续积累，保持长期主义，慢慢建立自己的系统。

**优**

> 先固定一件事：每周只发一条，但发之前完整读一遍。
> 读的时候只找一处听不懂的地方，改掉它。
> 这招在你已经有素材时有效；如果连题目都还没定，先解决选题，不要先追频率。
> 大多数人卡在第二周，因为改一遍比多发一条难受。

动作、场景、边界、失败点齐备，而且没有一句承诺结果。

## 与说服腔的边界

给动作**不等于**给承诺。

- 可以写：这样做之后，你更容易发现哪句话让人走神。
- 不可以写：这样做三个月一定能起号、一定能赚到钱。

绝对化承诺仍属 H 类零容忍项，命中即 FAIL（见 `anti-cliche-patterns.md`）。

## CLEAN 模式限制

洗稿时不得凭空添加动作、场景、边界或失败点。原稿缺失时只标注「价值缺环」，由作者补写。
