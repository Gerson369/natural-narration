# Value Chain｜价值链（v0.3.0 新增）

前三层解决「不像模板」，故事层解决「值得听下去」，价值链解决另一个更前面的问题：

> **这条内容到底有没有值得讲的东西。**

一篇稿子可以完全自然、完全有画面，却仍然什么都没交付。价值链就是用来拦住这种稿子的。

## 六个环节

真实问题 → 核心判断 → 事实或案例 → 实际影响 → 可执行动作 → 适用边界

| 环节 | 要回答什么 | 缺失时的症状 |
| --- | --- | --- |
| Problem 真实问题 | 观众正卡在什么地方 | 听着有道理，但不知道跟自己什么关系 |
| Judgement 核心判断 | 这条内容主张什么，且不完全显然 | 全篇都是共识，等于没讲 |
| Evidence 事实或案例 | 凭什么这么说 | 变成个人感受和口号 |
| Impact 实际影响 | 这个判断会改变什么选择 | 知道了，但不影响任何决定 |
| Action 可执行动作 | 观众可以先做什么 | 只有觉悟，没有下一步 |
| Boundary 适用边界 | 什么情况下不适用 | 局部经验被写成普遍规律 |

## 门禁规则

- 核心判断必须能用一句普通话说出来，并且**不能只是「很重要」「值得思考」「带来启示」「提升认知」**。
- 方法论、商业、成长、创作者、工具类内容：Action 与 Boundary 必须齐备（见 `practical-value-router.md`）。
- 科普、人物、纪录片类内容：Action 可以省略，但 Judgement、Evidence、Boundary 必须成立。
- 六项中缺三项以上 → 不是语言问题，回到选题层重写。

## 不合格的价值句

这些句子看起来在给价值，其实没有交付任何东西：

- 表达能力非常重要
- 认知决定了你的上限
- 我们要保持长期主义
- 建立自己的系统
- 持续积累就会有复利
- 这件事值得我们深思
- 它会带来巨大的影响

判定方法：把这句话原样念给一个反对者听，如果对方也会点头，说明它没有信息量。

## 对照

**差**

> 表达能力决定了你的机会上限，所以我们应该努力提高表达能力。

问题：没有真实问题，判断是共识，没有证据，没有动作，也没有边界。

**优**

> 开会发言总被忽略，不一定是观点不够好。
> 很多人会先讲五分钟背景，讲到第六分钟，别人还不知道你希望这场会决定什么。
> 下次可以先说结论，再补两条依据。
> 这招在决策型会议里有效，在需要争取共识的场合，反而要先讲过程。

问题 → 判断 → 具体过程 → 动作 → 边界，全部落地。

## 与既有层的关系

- 价值链不产生修辞，只决定内容顺序和取舍。
- 与写前五问 APSSV（`audience-problem-scene.md`）的关系：APSSV 决定「讲给谁、为什么讲」，价值链决定「讲完交付了什么」。
- 与故事层的关系：故事让判断可看见，不能代替判断。故事很足但判断为空，仍然 FAIL。
- 冲突时的让步顺序不变：事实 → 清晰 → 自然 → 故事感。

## CLEAN 模式的红线

MODE B 洗稿时**不得为了补齐价值链而增加原文没有的观点、动作或结论**。
发现原稿价值链缺环，只在正文之后单列一行「价值缺环」提示，由作者决定是否补写。
