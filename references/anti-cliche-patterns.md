# AI Cliché Pattern Library（词汇层）

使用方式：这里的每一条都是 **高风险信号**，不是禁词。命中时先问三个问题：

1. 这句话有新增信息吗？（没有 → 删）
2. 这个结构是不是在承担必要的信息澄清？（不是 → 改成直陈事实）
3. 删掉它之后，句子还成立吗？（成立 → 删）

全文配额（单篇 300–800 字口播稿）：

| 类别 | 默认上限 |
| --- | --- |
| A 二元反转 | 1 次（能不用就不用） |
| B 假悬念 | 0 次 |
| C 假反问 | 1 次（全文核心问题才算） |
| D 主持人腔 | 0 次 |
| E 伪金句 | 0–1 次（必须有新信息） |
| F 排比 | 1 组 |
| G 强行宏大化 | 0 次 |
| H 说服腔 / 绝对化承诺 / 身份优越 | 0 次（零容忍，命中即 FAIL） |

## A. 二元反转

高风险：不是 A，而是 B；不是 A，更不是 B；并不是 A，而是 B；真正的 A 是……；真正……的不是……；你以为……其实……；看似……实际上……；与其说……不如说……；它不是……它只是……

判定：只有当“错认知真实存在且广泛”，否定才有信息价值。否则直接给事实。

- 差：真正被加热的不是整个天空，更不是闪电本身，而是闪电通道里的空气。
- 优：电流经过时，闪电通道里的一小股空气会被瞬间加热到接近三万摄氏度。

## B. 假悬念

高风险：真正可怕的是；更不可思议的是；更夸张的是；事情还没有结束；这还只是开始；更大的问题还在后面；答案可能超出你的想象；事情远没有那么简单；接下来发生的事情；但别急；先别急着下结论；直到这里，故事才真正开始

判定：看后一句。后一句没有明确的信息升级（新数字 / 新事件 / 新后果），删掉过渡，直接给信息。

## C. 假反问

高风险：问题来了；这意味着什么；为什么会这样；到底有多夸张；它到底有多大；科学家是怎么知道的；那么问题又来了

判定：问完马上自答、且不是全文核心问题 → 直接陈述答案。一条短视频原则上只需要一个主问题。

## D. 主持人腔

高风险：值得注意的是；事实上；有意思的是；更重要的是；说到这里；简单来说；换句话说；所以你会发现；我们不妨；我们来看；接下来看看；这就是为什么；不难发现

判定：删除后句子仍完整 → 删，从事实开头。

- 差：值得注意的是，这种温度持续时间非常短。
- 优：这种高温只持续极短的时间。

## E. 伪金句

高风险：它虽然……却……；它只……却足以……；短短……却……；看起来……背后却……；从某种意义上来说；也许真正值得思考的是；人类终于意识到；宇宙再次告诉我们；大自然从来不会；这既是……也是……；真正让人震撼的不是……

判定：只是把上一句重新包装 → 删。普通信息句本身已经成立，不需要加工。

- 差：而这个数字，已经远远超过了我们熟悉的太阳表面。
- 优：太阳光球层大约 5500 摄氏度。

## F. 三段式 / 排比成瘾

识别：没有A。没有B。没有C。｜它会A，会B，还会C。｜不是A，不是B，而是C。

判定：排比本身有传播价值（能当重点句、能被转发）才保留一组；否则拆回自然语言，并合并成一句完整口播句。

## G. 强行宏大化

识别：这场发生在……的……；这一刻……；人类……；宇宙……；自然……；命运……；文明……；时间的礼物；敬畏；渺小

判定：普通知识点突然被放大为宏大哲理 → 不升格。宏大词只有在它本身就是事实主体（例如“旅行者一号飞出日圈”）时才用。

## H. 说服腔 / 绝对化承诺 / 身份优越（v0.2.0 新增）

这一类不来自文艺腔，而来自讲师型、课程型、带货型口播，在方法论内容里出现频率最高。

高风险：一定能赚到钱；绝对能成功；彻底改变你的人生；你的生活一定会改变；照我说的去做；记住我这句话；收藏起来反复多听；我和你们不一样；我们俩不在一个档次；你根本不懂；普通人永远做不到

判定：三个信号任一成立就必须改。

1. 把不确定的结果写成确定的因果（收入、成功、人生改变）。
2. 用身份高低代替论证（我 vs 你 / 普通人）。
3. 向观众下指令而不是交付信息（收藏、反复听、照做）。

改法：承诺降级为条件表述，身份对立改为行为差异。

- 差：只要你肯坚持，做口播绝对能成功，三个月彻底改变你的人生。
- 优：每天录一条，三个月后你对需求的判断会变快；它不等于收入，只是把机会往前推了一步。
- 差：你是一个拍短视频的人，我是一个做作品的人，我们俩不在一个档次。
- 优：有人录完就发，有人录完会回听一遍，标出哪句话让人走神。

限定词（大约、通常、未必、不等于）不是语气软，而是信息的一部分，不得为了“有力量”删掉。

## 换词不换结构 ＝ 没改

以下三句属于同一结构，不能互相充当修改：

- 你以为 A，其实 B。
- 看起来是 A，实际却是 B。
- 表面上 A，背后却 B。

都属于 `Expectation→Reversal`，按同一配额计算。详见 `syntax-pattern-detection.md`。

## I 类｜编辑过程残留与万能背景（v0.5.0 新增）

成稿里出现这些句子，说明改写流程漏进了正文，或者开头用了与主题无关的大背景。

- 编辑残留：下面是优化后的版本、根据你的要求、希望这篇对你有帮助、如果你需要我还可以、我将从以下几个方面。
- 万能背景：在当今……时代、随着……飞速发展、在……大背景下。

改法：编辑残留直接删除；万能背景换成与主题直接相关的事实，或直接从第二句开始。

## 中文补充检查（v0.5.0 新增，轻度）

- 长定语：一个分句 ≥ 22 字且「的」≥ 3 个，连续出现 ≥ 2 处时 Clarity 扣 1。改法：拆成主谓句。
- 「进行 / 加以 + 动词」：「进行分析」→「分析」。出现 ≥ 2 处时 Clarity 扣 1。技术文体里的固定术语可保留。
- 无来源权威：「专家认为 / 研究表明 / 数据显示」后面没有具体来源。开启 `--evidence-gate` 时判 FAIL。改法：写出来源，或写明「来源未具名」。
