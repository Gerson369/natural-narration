# 交稿前检查清单

语言层

- [ ] 同类认知反转 ≤ 1 次，且确实在澄清常见误解
- [ ] 人工悬念 0 次（“事情还没结束”类全部删除）
- [ ] 自问自答 ≤ 1 次，且是全文主问题
- [ ] 主持人过渡 0 次
- [ ] 伪金句 0 次，没有重新包装上一句的句子
- [ ] 结尾没有人生感悟、宇宙哲理、自然敬畏
- [ ] 没有夸大词（瞬间、彻底、绝对、永远）代替具体数据
- [ ] 没有绝对化承诺（一定能赚到、绝对成功、彻底改变人生）
- [ ] 没有身份优越句（我和你们不一样、不在一个档次）
- [ ] 没有向观众下指令的句子（收藏起来反复听、照我说的做）
- [ ] 限定词（大约、通常、未必、不等于）没有为了“有力量”被删掉

结构层

- [ ] 十一个结构 ID 均在配额内
- [ ] 没有换词不换结构的假修改
- [ ] 没有连续 3 句高潮
- [ ] 没有同二字开头在全文出现 ≥ 3 次
- [ ] “却 / 然而 / 反而”密度正常

节奏层

- [ ] 短 / 中 / 长句混搭，句长不机械均匀
- [ ] 没有 ≥ 4 句连续极短句
- [ ] 字幕行 12–24 字，没有单词成行

故事层（v0.2.0 新增）

- [ ] 每段都能说出叙事主体，不是只有「知识」在场
- [ ] 全文至少有一个可以看见的具体场景
- [ ] 至少有一处状态变化（之前 → 之后）
- [ ] 没有连续 4 句以上的抽象段落
- [ ] 场景、动作、发现过程均有资料支撑，没有编造心理活动或现场对话

价值与清晰度层（v0.3.0 新增）

- [ ] 价值链六项至少凑齐四项，核心判断只有一个
- [ ] 没有空泛价值句（很重要 / 值得思考 / 带来启示 / 提升认知）
- [ ] 没有伪实用建议（努力 / 坚持 / 持续积累 / 建立自己的体系）
- [ ] 方法论 / 商业 / 成长类已给出适用边界或例外条件
- [ ] 没有连续 3 句以上的格言句堆叠
- [ ] 每句只干一件事，“这 / 它”指代明确
- [ ] 删掉修辞后，核心判断仍然成立

信息层

- [ ] 所有数字、单位、时间、尺度与原稿一致
- [ ] 限定词（大约、接近、目前资料显示）保留
- [ ] 因果关系与信息顺序未被改写
- [ ] 事实可疑点已单独标记，未静默修改

语义保真层（v0.5.0 新增）

- [ ] 否定词全部保留（不 / 没有 / 尚未 / 并非 / 无法）
- [ ] 「可能 / 疑似 / 据称」没有被改成「确定 / 就是 / 一定」
- [ ] 「计划 / 正在 / 尚未」没有被改成「已经 / 完成」
- [ ] 条件与前提仍在（如果 / 只有……才 / 除非）
- [ ] 范围词一致（至少 / 超过 / 仅 / 其中 / 人次与人数）
- [ ] 观点仍归在原来的人或机构名下
- [ ] 相关没有被写成因果
- [ ] 每处改动都有收益，通顺句原样保留（No-op Rule）
- [ ] 成稿没有编辑残留（下面是优化后的版本 / 希望对你有帮助）
- [ ] 有作者样本时，没有迁移样本里的经历、数据、观点或身份
- [ ] Markdown 文件：结构部分未动，`nn_structure_check.py` PASS

传播层

- [ ] 开头仍有钩子，且钩子来自事实
- [ ] 不像百科、教材、说明书、新闻通稿
- [ ] 读出来像人在说话

评分门禁

- [ ] Naturalness ≥ 8
- [ ] Cliché Risk ≤ 2
- [ ] AI Pattern Risk ≤ 2
- [ ] Information Preservation ≥ 9
- [ ] Clarity ≥ 8
- [ ] 说服腔命中（H 类 + Superiority Contrast + Overclaim Promise）= 0
- [ ] Story Strength ≥ 6（叙事 / 人物 / 纪录片 / 方法论类任务）
- [ ] Value Strength ≥ 6（方法论 / 商业 / 成长 / 创作者 / 工具 / 慢创业类任务）
- [ ] Evidence Strength ≥ 6，类比越界 = 0，无来源权威 = 0（历史 / 科普 / 纪录片类）
- [ ] Semantic Fidelity ≥ 9，否定 / 确定性 / 状态 / 归因问题 = 0（CLEAN 任务）
