# 工作流

## MODE A — WRITE（从零写自然口播）

> v0.8.0：第 2 步前先搭首稿蓝图（`first-draft-blueprint.md`、`topic-templates.md`）；第 8 步改为交稿前自审循环（`self-review-loop.md`），结构分 ≥ 85 才交稿，最多 3 轮，只交最终稿。

0. **写前五问（STEP 0，v0.2.0 新增）**：Audience 讲给谁听、Problem 对方卡在什么问题、Scene 问题发生在什么场景、Solution 给什么办法、Value 听完能做到什么。答不上三个以上先补资料，不开写。详见 `audience-problem-scene.md`。
0.5 **价值链六问（STEP 0.5，v0.3.0 新增）**：真实问题 → 核心判断 → 事实或案例 → 实际影响 → 可执行动作 → 适用边界。缺三项以上回到选题层。详见 `value-chain.md`、`practical-value-router.md`。
1. 列事实清单：数字、时间、尺度、因果、限制条件（缺了就少写，不编）。
2. 选钩子：从结果 / 极端数字 / 时间 / 尺度 / 后果 / 具体场景 / 真反常事实中选一。
3. 排推进顺序：事实 → 动作 → 原因 → 结果 → 数字 → 时间 → 尺度 → 限制条件 → 下一事实。
4. **挂上故事引擎（v0.2.0 新增）**：确认叙事主体，选一个可看见的场景起点，安排一处状态变化，必要时写出发现路径与视角移动，只用有资料支撑的内容。详见 `story-engine.md`。
5. 逐句写下去，每句自问：一个真正懂这件事的人坐在朋友旁边解释，会这样说吗？
6. 节奏调整：短 / 中 / 长句搭配，字幕行 12–24 字。
7. **讲清楚测试**：删掉金句、反问、情绪词后，观点、因果、办法是否仍然成立。
8. 跑 SCAN 与评分（叙事类加 `--story-gate`，方法论 / 商业 / 成长类加 `--value-gate`），不达标就改，改完再扫。
9. 交稿（默认不输出扫描过程）。

## MODE B — CLEAN（清洗现有稿子）

0. **文体路由与声音（v0.5.0）**：判断 SPOKEN / ARTICLE / TECHNICAL / PERSONAL；有作者样本时启用 AUTHOR_MATCH；Markdown 文件启用 FILE MODE。详见 `register-router.md`、`author-voice-match.md`、`file-mode.md`。
1. **保留原始信息**：先把原稿的事实、数字、因果、信息顺序、核心观点列成清单（内部）。
1.5 **锁定语义锚点（v0.5.0）**：否定、确定程度、状态、条件、范围、归因、因果。详见 `semantic-fidelity.md`。
2. **检测 cliché**：按 A–H 逐项标记词汇层命中，H 类（说服腔 / 绝对化承诺 / 身份优越）零容忍。
3. **检测重复句法**：按十一个结构 ID 打标签，统计频率。
4. **重写**（先问这处改动有没有收益；没有就原样保留，No-op Rule）：每一处先问“这句话承担什么信息功能”，然后用直陈事实重写；没有信息功能的句子直接删。承诺降级为条件表述，身份对立改为行为差异。
5. **补具体（v0.2.0 新增）**：连续 3 句以上没有场景、动作、时间或数字时，按 Concrete Scene Router 补入真实案例、具体动作、时间限制、空间场景或一次选择的后果；资料不足就不补，不编。
6. **再扫描**：重新打标签 + 评分，确认不是换了一批同义模板。
7. **信息保留校对**：逐项比对第 1 步清单，任何丢失必须补回。
7.5 **语义保真校对（v0.5.0）**：逐类比对第 1.5 步的锚点；有文件时跑 `--fidelity-gate`，Markdown 再跑 `nn_structure_check.py`。
8. 事实问题与语言问题分开报；事实问题列成“待核”，不静默修正。
9. **价值链检查（v0.3.0 新增）**：只删空泛价值句与伪实用建议，不新增原文没有的观点或动作；缺环写成「价值缺环」提示交给作者。

10. **CLEAN 到顶提示（v0.8.0）**：清洗后结构分仍 < 85，写明「结构需重组」，用户同意后按 MODE A 蓝图、只用原稿事实重写。

v0.5.0 补充：保留原意、别改我的意思、按我的风格、直接改这个 Markdown 文件。

写新口播稿、短视频脚本、科普稿、人物故事、哲学 / 认知内容、方法论内容、纪录片式解说时，默认也适用。

## 与其他 Skill 的分工

- 小说 / 网文文学精修：交给 `anti-ai-flavor-editor`（长篇连贯性、类型路由、改写强度分级）。
- 事实核查：交给可信内容核查类工作流，本 Skill 只标记可疑点。
- 本 Skill 只管中文口播 / 知识类文本的句法级去模板化与故事层强化。
