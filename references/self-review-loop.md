# 交稿前自审循环（v0.8.0）

原则：**修改在 Skill 内部完成，不留给用户。** 用户只看到最终稿。

## 循环

1. 写完初稿后，按下表逐项自评（内部，不输出）。
2. 任一硬门禁未过 → 只重写出问题的段落，不重写整篇。
3. 再评。最多 3 轮。
4. 3 轮后仍未过：交出当前最好的一稿，并在正文后用一行写明卡在哪里（多半是资料不足），不假装达标。

## 门禁表

| 项 | 门槛 | 工具 |
|---|---|---|
| 结构分 | ≥ 85 / 100 | `nn_blueprint_check.py --gate` |
| 主线离场 | 不超过上限；脱离主线的段落 ≤ 1 | 同上 |
| 总结式结尾 | 0 | 同上 |
| 口播自然度 | Naturalness ≥ 8，套话与句法配额达标 | `nn_scan.py` |
| 证据边界 | 无无来源权威、无类比越界；演示标为演示 | `nn_scan.py` + 人工 |
| 好句 | 锁定句全部保留 | `nn_scan.py --protect` |
| 凑节奏句 | 0（只是换说法、没有新信息的句子） | `nn_blueprint_check.py` + 人工 |

## 人工自问（脚本报不到的）

- 删掉任意一段，主问题是否变得答不上？答得上就说明这段可以删。
- 观众在第几句会划走？那里多半是在讲解而不是在发生。
- 结尾最后一句是画面/动作，还是总结？

## 说明

脚本分数是代理指标，用来拦住明显的结构问题，不等于观众测试。`--story-gate` / `--evidence-gate` 的代理分在 v0.6.1 复跑中未能区分自然度变化，v0.8.0 起在 WRITE 自审里只作参考，结构以 `nn_blueprint_check.py` 为准。


## v0.8.1 自审新增项

- 主线是不是题目本身？是 -> 先换主线，再重写。
- 开头 / 中段 / 结尾都有主线吗？
- 揭底点 ≥ 3，主揭底在 20%–60%，相邻间距 ≤ 35%，连续讲解 ≤ 4 句。
- 不达标只重写揭底之间那一段，不为凑揭底而编造事实；事实不够就标「事实待核」。


## v0.9.0 调整

- 「结构分 ≥ 85」不再是交稿门槛。`nn_blueprint_check.py` 只给 LOW / MEDIUM / HIGH 与带位置的风险清单，由人判断。
- HIGH 或明显结构问题：交回编剧（见 `structure-handoff.md`），不在本 Skill 里反复改写。
- 「删掉仍能回答主问题」不足以删段；还要看它是否承担理解、证据、节奏、幽默或情感功能。
- 揭底与主线规则改为风险提示：问题链式结构可以不靠同一个主线词。
