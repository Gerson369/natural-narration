# Evidence-led Narration｜证据驱动叙事（v0.4.0）

## 目标

让证据推动判断变化，而不是把史料、数字和案例排成资料清单。

## Evidence Arc

按需使用以下顺序，不把它写成可见模板：

1. **Working Assumption**：明确当前待检验的判断，不虚构“所有人都误解”。
2. **Evidence 1 — Crack**：第一份证据只负责让旧判断出现裂缝。
3. **Evidence 2 — Range**：第二份不同类型或不同地点的证据扩大适用范围。
4. **Evidence 3 — Pattern**：第三份证据确认重复出现的模式；没有第三份时不得假装形成共识。
5. **Bounded Conclusion**：写清证据支持什么、不能证明什么、结论适用于哪里。

证据数量不是硬指标。一个高质量证据也可能胜过三个装饰案例。

## 每份证据三问

- 它证明了什么？
- 它不能证明什么？
- 它怎样推动叙事进入下一步？

如果删除某份证据后结论完全不受影响，它大概率只是装饰。

## 证据角色

- `CRACK`：削弱旧判断。
- `RANGE`：扩大时间、地区、人群或机制范围。
- `PATTERN`：确认重复模式。
- `LIMIT`：限定外推边界。

内部规划时可标角色，成稿不输出标签。

## 禁止

- 先定结论，再挑相似案例背书。
- 用单个遗址、个案或轶闻代表整个人类历史。
- 把“同时出现”写成“前者导致后者”。
- 为增强戏剧性编造研究者反应、现场对话或心理活动。
- 连续报资料名，却不解释每份资料改变了什么判断。

## Evidence Gate

叙事型科普、历史、人物和纪录片稿可运行：

```bash
python3 scripts/nn_scan.py draft.txt --evidence-gate
```

脚本只检查证据密度、推论连接、边界表达和明显类比越界；“证据是否真实、是否足以支持结论”仍必须人工核查。
