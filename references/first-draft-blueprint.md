# 首稿蓝图（First-Draft Blueprint，v0.8.0）

目标：新选题的**第一稿就能直接用**。CLEAN 只能调表达，补不了结构；结构必须在动笔前定好。
蓝图是内部工作稿，默认不输出给用户。

## 七项蓝图（缺一项不开写）

1. **题材模板**：从 `topic-templates.md` 选一个（文物/历史、人物、科普、方法论、观点/哲学）。
2. **主问题**：全文只追一个问题，写成观众会问的一句话。开头抛出，结尾落地。
3. **主线词**：3–6 个词（场景、物件、那一局/那一条/那一样品），用来让每段都回到同一条线。
4. **连续的线**：用箭头写出一件事从头到尾的状态变化（A → 受阻 → 选择 → 后果 → 边界 → 回到 A）。不要写成「例子1 / 例子2 / 例子3」。
5. **事实清单**：每条事实带限定词和来源；写稿只用清单里的事实。演示/假设必须标成演示/假设。
6. **每段功能**：每段一句话写它推进了主问题的哪一步。写不出来的段落删掉或并入主线。
7. **笑点与结尾**：列出要锁定的好句（见 `line-protection.md`）；结尾落在一个具体画面或动作上，不加总结句。

## 三条硬规则

- **一条线原则**：多个材料必须挂在同一个场景或同一个问题上。材料无法服务主问题时，宁可不用。
- **发生压过解释**：规则、原理、定义要嵌在一次正在发生的过程里讲（带观众打一局、走一遍、做一次），不单列一段说明书。
- **不新增事实**：演示局可以假设，但必须标明；不得把演示写成古人真实发生过的比赛。

## 蓝图文件格式

蓝图里写一行 `主线词：词1,词2,词3`，即可用 `scripts/nn_blueprint_check.py draft.txt --blueprint blueprint.md --gate` 自检结构。样例见 `tests/first-draft/*/blueprint.md`。


## v0.8.1 补充：题目词与揭底行

蓝图新增两行，缺一不开写：

- `题目词：`题目本身的词。主线词不能与之相同或互相包含。主线必须是具体的人 / 物 / 场景。
- `揭底：`至少 3 个揭底点，第一个是主揭底，放在全文 20%–60%。

详见 `references/reveal-beats.md`。


## v0.9.0：主线也可以是一条问题链

好结构不只「跟着一个物件」。每段写清：当前疑问 → 交付的答案 → 新增理解 → 下一问，也能贯穿全文。结构主责在叙事编剧技能；本 Skill 写稿时只搭轻量蓝图。
