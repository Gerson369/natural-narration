# 写前五问与讲清楚测试（v0.2.0 新增）

语言层解决「这句话怎么讲得自然」，这份文件解决「为什么要讲这句话，讲给谁听」。

## 写前五问 A-P-S-S-V

开写之前，内部先回答五个问题。**默认不输出给用户**，只用于决定内容顺序和取舍。

| 代号 | 问题 | 不合格的答案 |
| --- | --- | --- |
| Audience | 讲给谁听 | 「所有人」「大众」 |
| Problem | 对方正在遇到什么问题 | 「想学知识」 |
| Scene | 这个问题通常发生在什么具体场景 | 空着不写 |
| Solution | 这条内容提供什么解决办法或解释 | 「讲清楚这个现象」 |
| Value | 听完之后对方能理解或做到什么 | 「涨知识」 |

五问答不出三个以上，说明选题本身没想清楚，先补事实和场景，不要直接开写。

科普 / 纪录片类的 Problem 可以是「认知缺口」而不是「生活痛点」，例如「大多数人只知道结果，不知道它是怎么被测出来的」。

## Explanation Test｜讲清楚测试

交稿前做一次删除测试：**把金句、反问、情绪词、修辞全部删掉，只留信息句。**

然后回答三个问题：

1. 观点是否仍然清楚？
2. 因果链是否完整？
3. 解决办法是否可执行、可验证？

如果删掉修辞后内容就撑不住，问题不在语言层，而在于作者还没有把这件事想明白。此时应回到事实层重写，而不是补更多修辞。

这项测试与「洗成百科」不冲突：测试是内部检验，成稿仍然要保留钩子和口语节奏。

## 说服腔风险（对应 H 类）

讲师型、口播带货型内容最常见的 AI 味不是文艺腔，而是说服腔：

- 绝对化承诺：一定能赚到钱、照我说的做、生活一定会改变。
- 身份优越：我和你们不一样、我们俩不在一个档次。
- 高密度自问自答：一句话问一次，连续推进。
- 同义反复：同一个意思换四种说法反复强调。

处理原则：

1. 承诺降级为条件表述——把「一定能赚到钱」改成「能提高表达和判断需求的能力，这是收入的前提之一，但不等于结果」。
2. 身份对立改为具体差异——把「我们不在一个档次」改成「有人只是在完成拍摄，有人同时在训练需求判断」。
3. 自问自答压缩到全文 1 次。
4. 同义重复保留信息量最大的一处。

## 发布后反馈复盘（可选）

这些是**信号，不是因果结论**，不能反向证明内容质量：

| 现象 | 优先排查 |
| --- | --- |
| 前 3 秒划走 | 开头没有建立相关性，或信息进入太慢 |
| 看完率高 | 推进顺序基本成立 |
| 收藏多 | 提供了可复用价值 |
| 评论多 | 触发了问题、共鸣或争议 |
| 关注少 | 单条价值成立，但没有让人预期到持续价值 |

复盘只用来修正下一条的选题与结构，不作为改事实的理由。
