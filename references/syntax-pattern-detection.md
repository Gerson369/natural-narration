# 句法重复模式检测（本 Skill 的关键能力）

AI 可以避开某个词，却继续使用完全相同的结构。因此审稿必须检查**结构频率**，不只是关键词频率。

## 十一个结构 ID

| ID | 定义 | 识别方法 | 单篇配额 |
| --- | --- | --- | --- |
| `Expectation→Reversal` | 先给预期再推翻 | 同一句内同时出现预期标记（你以为 / 很多人以为 / 看似 / 表面上 / 看起来 / 听起来 / 印象中）与反转标记（其实 / 实际上 / 事实上 / 却 / 而是 / 真正） | ≤ 1 |
| `Negation A→Reveal B` | 先否定再揭晓 | 不是 / 并非 / 并不是 … 而是 / 更不是 / 它只是 | ≤ 1 |
| `Question→Immediate Answer` | 问号句紧接自答 | 句尾为？且下一句为陈述句 | ≤ 1（仅全文核心问题） |
| `Suspense Cue→Fact` | 悬念提示词 + 本身无信息 | 提示句不含新数字 / 新事件且长度短 | 0 |
| `Host Transition→Fact` | 主持人过渡开头 | 句首为主持人腔词表任一项 | 0 |
| `Three-beat Escalation` | 三段式递进 | 连续三个分句开头二字相同 | ≤ 1 组 |
| `Repeated Parallelism` | 全文反复同开头 | 同一分句开头二字全文 ≥ 3 次 | 0–1 |
| `Repeated Contrast` | 对比滥用 | 却 / 然而 / 反而 / 相反 密度 > 1.2 次 / 100 字 | 0 |
| `Fact→Artificial Philosophical Summary` | 事实后接人工升华 | 末尾 1–2 句含宏大词且无新信息 | 0 |
| `Superiority Contrast` | 用身份高低代替论证 | 同一句内同时出现我 / 咱 + 你 / 你们 / 普通人 / 别人 + 不一样 / 档次 / 层次 / 级别 / 差距 | 0 |
| `Overclaim Promise` | 无条件承诺结果 | 同一句内出现一定 / 必然 / 绝对 / 永远 / 100% + 赚 / 成功 / 改变 / 做到 / 实现，且没有任何限定词 | 0 |

## 审稿时的做法

1. 把稿子拆成句列表，逐句打结构标签（一句可以多标签）。
2. 统计每个结构 ID 的出现次数，而不是统计词。
3. 超配额的结构，保留信息价值最大的那一处，其余重写为直陈事实。
4. 重写后重新打标签，确认不是“换了一批同义模板”。
5. 检查相邻句：连续 3 句带任意结构标签 → 重写这一段。

## 常见“假修改”

| 看起来改了 | 实际仍是 |
| --- | --- |
| 你以为…其实… → 看起来…实际却… | `Expectation→Reversal` |
| 不是 A 而是 B → 与其说 A，不如说 B | `Negation A→Reveal B` |
| 事情还没结束 → 而这只是开端 | `Suspense Cue→Fact` |
| 也许真正值得思考的是 → 或许我们真该想想的是 | `Fact→Artificial Philosophical Summary` |
| 值得注意的是 → 一个容易被忽略的细节是 | `Host Transition→Fact` |
| 我们俩不在一个档次 → 我跟你们不是一个层次 | `Superiority Contrast` |
| 一定能赚到钱 → 百分之百能做到 | `Overclaim Promise` |

## 自动校验

有文本文件时可以直接跑硬指标：

```bash
python3 scripts/nn_scan.py draft.txt
```

输出包含：词汇命中数、结构命中数、各结构 ID 频率、句长均值与离散度、连续高潮句长度、故事层指标、说服腔命中数、七项评分与 PASS/FAIL。
`Superiority Contrast` 与 `Overclaim Promise` 属于零容忍项：只要命中，无论其他评分多高，结果都是 FAIL。
脚本是辅助坐标，最终判断仍由语义审稿完成：脚本不会告诉你“这次反转是否必要”。
