# 失败模式与修复动作

| 失败模式 | 表现 | 修复动作 |
| --- | --- | --- |
| 换词不换结构 | “你以为…其实…”变成“看起来…实际却…” | 按结构 ID 重新计数，删到配额内，重写为直陈事实 |
| 机械禁词 | 把所有“不是 / 其实 / 真正”删到句子不通 | 恢复必要的一处，优先保中文自然 |
| 洗成百科 | 只剩定义句，没有发生了什么 | 加回动作、后果、具体场景，不加形容词 |
| 句子碎片化 | 连续短句、单词成行 | 合并为 12–24 字完整口播句 |
| 事实漂移 | 为了好听删限定词或改数字 | 回溯事实清单，逐项比对，恢复限定词 |
| 升华回流 | 结尾又出现宇宙 / 人类 / 意义 | 结尾换成新信息或一个具体自查问题 |
| 钩子被削平 | 开头变成无信息导语 | 用极端数字、时间、后果重建开头 |
| 重复开头 | 多个分句同二字开头 | 改主语、改语序、合并句子 |
| 对比滥用 | “却 / 然而”密度过高 | 只保留真有对比关系的一处 |
| 夸大词回流 | 瞬间、彻底、绝对、永远 | 换成具体时间与范围 |
| 假设当观测 | 把假设场景写成已发生 | 加上“假设”标记或删除 |
| 人物神化 | 天才叙事、单一原因归因 | 改写成具体动作与长期习惯 |

## 上下文失败

- 用户只给了一句需求，事实不够：先列需要的事实点，宁可少写，不能编。
- 原稿事实本身可疑：语言问题和事实问题分开报，不在洗稿里静默修改。
- 用户同时要求“保留原句”和“去模板”：优先保留原句，只删无信息过渡句，并说明取舍。

## v0.2.0 新增失败模式

| 现象 | 原因 | 修复动作 |
| --- | --- | --- |
| 读起来像讲师在台上说教 | 说服腔：绝对化承诺 + 身份优越 + 高密度自问自答 | 承诺降级为条件表述，身份对立改为行为差异，自问自答压到 1 次 |
| 语言很自然，但听完记不住任何画面 | 只有解释层，没有故事层 | 按 Concrete Scene Router 补入案例、动作、时间、场景或后果 |
| 全篇都是方法论词汇（底层逻辑、思维方式、闭环） | 抽象密度过高，连续 4 句以上不落地 | 每 3 句至少落一次具体，抽象词保留信息量最大的一处 |
| 为了故事感补出了心理活动和现场对话 | 把故事化理解成写小说 | 删除无资料支撑的细节，只保留可核实的事实与顺序 |
| 扫描各项通过，但 verdict 仍是 FAIL | 命中说服腔零容忍项 | 逐条改写 H 类词汇与 Superiority Contrast / Overclaim Promise 命中句 |

## v0.3.0 新增失败模式（价值与清晰度层）

| 现象 | 原因 | 修复动作 |
| --- | --- | --- |
| 每句都对，听完不知道在说什么 | 没有唯一核心判断，只有一堆正确的抽象句 | 先写出一句可被反驳的核心判断，其余句子围着它重排 |
| 结尾都是「很重要 / 值得思考 / 提升认知」 | 空泛价值句充当结论 | 换成具体影响：谁、在什么情况下、会发生什么变化 |
| 给了建议，但没人能照着做 | 伪实用：努力 / 坚持 / 持续积累 / 建立自己的体系 | 换成可观察动作：什么时间、做多少、做完怎么知道成了 |
| 金句一句接一句，像语录 | 格言句连续 ≥ 3 句，没有事实插入 | 每一句判断后面接一个具体例子或数字 |
| 理论听起来全对，实际不能用 | 缺适用边界 | 补一句「什么情况下不适用」，带上代价 |
| 听不清「这」指的是什么 | 指代过多、一句多任务、分句过长 | 把指代词换回名词，长句拆成一句一件事 |
| 科普稿被硬塞行动建议 | 把价值门禁用错题材 | 科普 / 人物 / 纪录片类不开 `--value-gate`，只要求判断与边界成立 |
| 洗稿后多出了原文没有的观点 | 为凑齐价值链而代作者做主 | 删掉新增观点，改写成「价值缺环」提示 |

## v0.5.0 新增失败模式（语义保真层）

| 现象 | 原因 | 修复动作 |
| --- | --- | --- |
| 洗完变通顺了，意思却反了 | 否定词被删（尚未通过 → 通过了） | 对照原稿补回否定，跑 `--fidelity-gate` |
| 句子更有力，但比原文更确定 | 「可能 / 有关」被改成「就是 / 导致」 | 恢复原有确定程度与相关表述 |
| 计划中的事写成已经发生 | 状态词被合并或删除 | 逐句核对正在 / 计划 / 已经 |
| 对方的说法变成了叙述者的断言 | 归因主语被删 | 补回「谁声称 / 谁认为」 |
| 「超过 1200 人次」变成「1200 名用户」 | 范围词与统计口径被改 | 保留原口径，不把人次写成人数 |
| 通顺的句子被改得更书面 | 把修改率当成质量指标 | 执行 No-op Rule，跑 `--noop-gate` |
| Markdown 里的命令、链接、标题被改 | 把结构部分当成正文润色 | 启用 FILE MODE，跑 `nn_structure_check.py` |
| 按作者风格改完，多出了样本里的经历 | AUTHOR_MATCH 迁移了内容而不只是形式 | 删掉来自样本的事实，只保留句长与语气 |
| 技术文档被改成口播腔 | 没有做文体路由 | 按 `register-router.md` 归入 TECHNICAL，保留正式表达 |
