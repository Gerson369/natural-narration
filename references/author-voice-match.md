# AUTHOR_MATCH｜作者声音匹配（v0.5.0）

四种预设人格解决的是「没有作者参照时，用什么语气讲」。用户提供了作者样本，或原稿本身已有鲜明个人风格时，预设人格要让位给作者本人的声音。否则 Skill 会把所有人的稿子洗成同一种「自然口播标准腔」，这本身就是一种新的模板。

## 触发条件

满足任一条即启用：

- 用户提供了作者样本（「按我的风格」「参考我之前这篇」）。
- 用户明确要求保留个人语气。
- 原稿是第一人称随笔、评论或个人复盘，且风格稳定。

## 优先级

1. 用户的明确要求
2. 作者样本
3. 原稿已有的语域
4. 预设人格（`DEFAULT_NATURAL` 等）

## 从样本中学什么

只学表达形式，五项：

| 维度 | 观察什么 |
| --- | --- |
| 句长 | 偏短句还是长句，长短如何交替 |
| 用词 | 常用口头词、术语密度、书面还是口语 |
| 标点 | 破折号、括号、省略号、问号的使用习惯 |
| 语气 | 犹豫、幽默、直接、克制、自嘲 |
| 推进方式 | 先结论还是先场景，习惯怎样收尾 |

## 绝对不迁移

- 样本中的经历、事件、人物
- 样本中的数字、数据、来源
- 样本中的观点、立场、结论
- 样本中的身份信息

判断方法：把成稿中的每个事实拿出来问一句「它来自目标原稿，还是来自样本？」来自样本的，删除。

## 保留作者的「不完美」

作者原有的犹豫、保留意见、未下结论的状态，都属于作者声音，不能被洗成确定判断。

- 原稿：「我对全面取消人工校对有些拿不准。」
- 错误：「全面取消人工校对是不可取的。」
- 合格：「全面取消人工校对，我还拿不准。」

## 与预设人格的关系

- AUTHOR_MATCH 启用时，不叠加 `SLOW_ENTREPRENEURSHIP` 等人格的价值观。
- 六层检测和语义保真层仍然全部生效：作者习惯用的模板句（例如频繁的「不是 A 而是 B」）仍按配额处理，但优先保留作者确有意图的那一处。
- 作者样本本身带有 AI 腔时，只学句长与语气，不学模板结构。

## 输出

- 不在成稿中说明学了哪些特征。
- 用户要求时，可在正文之后用三行以内说明风格依据。
