# 题材结构模板（v0.8.0）

每个模板都是「让观众跟着一件事走完」，不是「分三点讲」。

## 文物 / 历史：带观众用一次
场景钩子 → 同一张桌/同一个地方拿出器物 → 用它完整走一遍（规则嵌在动作里）→ 结果引出下一件器物或下一个动作 → 证据边界 → 回到开头场景。
样例：`tests/first-draft/ancient-games/`

## 人物：跟着一个卡住的时刻走到转折
卡住的具体问题 → 她/他做了什么动作 → 发现了什么线索 → 做了哪个选择 → 结果（带数字）→ 边界（哪些是推断）→ 回到那个线索。不写履历，不写精神总结。
样例：`tests/first-draft/person-tuyouyou/`

## 科普：跟着一个对照实验走
日常选择 → 把它拆成可对照的两份 → 结果 → 机制（一句话，嵌在结果里）→ 反向操作验证 → 适用边界 → 回到那个选择。
样例：`tests/first-draft/science-bread/`

## 方法论：陪观众做一遍
具体时刻与堆积的任务 → 第一条用方法 → 第二条不适用 → 用坏的情况 → 明天可以做的一个动作（带时间或数量）。
样例：`tests/first-draft/method-two-minute/`

## 观点 / 哲学：一个场景里的两种选择
一个具体场景 → 第一种选择及其后果 → 第二种选择及其后果 → 观点在差别里自己出现 → 边界 → 回到场景。不写金句收尾。
