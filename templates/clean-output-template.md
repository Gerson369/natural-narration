**【保留不变】**

- 数字与单位：全部保留
- 限定词（大约 / 接近 / 目前资料显示）：全部保留
- 因果关系与信息顺序：未改
- 否定 / 确定程度 / 状态 / 条件 / 范围 / 归因：未改（v0.5.0）
- 本来就通顺的句子：原样保留（No-op Rule）
