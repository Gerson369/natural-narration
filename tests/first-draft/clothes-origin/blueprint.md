# 蓝图｜为什么古人类开始穿衣服

- 题材模板：科普（跟着一只体虱搬家）
- 主问题：人类是冷了才穿衣服的吗？
- 主线词：体虱,虱子,接缝,房子,屋子
- 题目词：衣服,穿衣服,服装
- 揭底：8.3万|小孔|只剩几万|十几万年的房子
- 连续的线：今天穿裤子 → 「冷了才穿」的坑 → 体虱分家的时间（主揭底）→ 体虱的房子有了接缝（骨针）→ 冰期里会缝的人活下来 → 边界 → 回到裤子的接缝
- 事实清单（均待核）：2011 年佛罗里达大学体虱分化估算 8.3–17 万年前；现代人大规模走出非洲约 7 万年前以后；丹尼索瓦洞鸟骨针约 5 万年（年代与归属有争议）；冰期人口瓶颈为区间估算
- 笑点锁定：史前的塑料袋；裤子已经不招租了
- 结尾落点：裤子的接缝，不加总结句
